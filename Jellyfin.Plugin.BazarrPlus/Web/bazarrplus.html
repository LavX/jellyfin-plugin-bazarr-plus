Bazarr+ Subtitles

This plugin fetches subtitles from a self-hosted Bazarr+ instance via the OpenSubtitles-compatible REST endpoint. Enable the endpoint in Bazarr+ under Distribution Hub → Settings first (Settings → External Integration on Bazarr+ v2.2 and v2.3).

e.g. http://bazarr.local:6767. No trailing slash. The plugin appends /api/v1/... itself.
Paste an API key from Bazarr+ Distribution Hub → API Keys (Settings → External Integration on Bazarr+ v2.2 and v2.3).
Bazarr+ is not affiliated with or endorsed by OpenSubtitles.com.
